## Importante
GitHub Pages puede alojar gratuitamente un catálogo estático. No procesa pagos, no guarda pedidos de forma segura ni envía órdenes automáticamente al proveedor. Esas funciones requieren servicios compatibles; algunos cobran comisiones o tienen costes. No se añadirán productos ni proveedores sin verificar sus condiciones.

**Seguridad:** nunca guardes contraseñas, claves API, datos de tarjetas ni información personal de clientes en este repositorio público.
